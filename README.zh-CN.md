# AI 论文阅读

个人持续更新的 AI 论文阅读收藏，以 PDF 形式存放在本仓库中，方便浏览、打开和跨设备同步。内容涵盖我主要关注的方向——视觉-语言-动作模型与具身智能、世界模型与联合嵌入预测架构（JEPA）、生成式与扩散模型、计算机视觉、多模态学习以及自然语言处理，并在每读完一篇论文后持续补充。

**English version: [README.md](README.md)**

## 目录结构

所有论文统一放在扁平化的 [`papers/`](papers) 目录下，文件名对应论文标题或其提出的方法名称。
