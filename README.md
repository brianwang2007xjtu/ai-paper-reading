# AI Paper Reading

A personal, continuously growing reading collection of AI research papers, kept as PDFs in this repository so they are easy to browse, open, and sync across machines. It gathers the work I follow most closely — vision-language-action models and embodied intelligence, world models and joint-embedding predictive architectures (JEPA), generative and diffusion models, computer vision, multimodal learning, and natural language processing — and new papers are added whenever I finish reading one.

**中文版文档：[README.zh-CN.md](README.zh-CN.md)**

## Repository Structure

All papers live in a single flat [`papers/`](papers) directory, and each file is named after the paper or the method it introduces.
